# Cookies MTL 🍪

La carte des cookies de Montréal — chaque cookie goûté, noté et localisé.
Montreal's cookie map — every cookie tasted, rated, and pinned.

Projet perso, en construction. Stack : Next.js · TypeScript · Tailwind CSS. Déployé sur Vercel.

## Développement

```bash
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).
